# 置信度综合指数（Confidence Index, CI）

> LPP Step 3 可选层 · 置信度指数 v1.0 · 2026-08-29 · △ 探索性
> 用途：把"这份画像有多可信"从措辞纪律（原则 7）升级为**可计算的综合分数**，与 `d_scan.py --multi` 直接挂钩。

## 为什么需要

原则 7 用 ■强 / ●中 / ▲弱 / △探索 约束措辞，但"什么算强信号"长期依赖主观判断。CI 把**样本量、场景命中、跨文本一致性、面具厚度、ND confound、语域覆盖**量化为 0-100 分，再映射回四级措辞纪律，使"置信度"可复算、可审计。

## 输入

- **样本集合**：同一对象的 ≥1 份文本，每份标注 `(context/Tenor, register, word_count)`。
- **脚本产物**：`d_scan.py --multi f1 f2 ...` 输出 `mask_thickness`（0-1）与 `cv_by_dim`（各 MASK_DIM 跨文本变异系数）。
- **LLM 产物**：Step 1 的 D 观察总条数 `total` 与成功映射到场景的条数 `mapped`；ND1-6 命中标记。

## 六个因子（各归一化 0-1，加权求和）

| 因子 | 符号 | 权重 | 计算 | 方向 |
|------|------|------|------|------|
| 样本量充分度 | S | 0.30 | 见下 | 高→高 |
| 场景命中率 | H | 0.20 | `mapped / total`（Step 1 观察 → 场景映射比例） | 高→高 |
| 跨文本一致性 | C | 0.20 | `1 - mean(cv_by_dim 中核心维的 CV)`；CV>1 取 0 | 高→高 |
| 面具厚度折减 | M | 0.15 | `1 - 0.5·mask_thickness`（来自 d_scan --multi） | 厚→低 |
| ND confound 校准 | N | 0.10 | 无 ND 标记=1.0；有标记且已按 nd-calibration 校准=0.9；有标记未校准=0.6 | 校准→高 |
| 语域覆盖度 | R | 0.05 | 采样语域数 ≥3=1.0；2=0.8；1=0.6 | 多→高 |

**样本量充分度 S 细则：**

- `n≥5` 且 `min(word_count)≥600` → 1.0
- `n=3-4` 且 `min≥300` → 0.8
- `n=2` → 0.6
- `n=1` 且 `≥300字` → 0.45
- `n=1` 且 `<300字` → 0.25（且 CI 上限锁定为 △探索，仅评 O/I，见原则 10）

**公式：**

```
CI = 100 × (0.30·S + 0.20·H + 0.20·C + 0.15·M + 0.10·N + 0.05·R)
```

## 四级映射（回到措辞纪律）

| CI 区间 | 措辞纪律 | 报告用语 | 含义 |
|---------|---------|---------|------|
| ≥75 | ■ 强 | "反映 / 显示 / 稳定呈现" | 多样本多语境，结论可高置信呈现 |
| 50-74 | ● 中 | "可能 / 倾向于 / 更像是" | 有一定证据，保留不确定性 |
| 25-49 | ▲ 弱 | "有限证据提示 / 尚不足以确定" | 样本或覆盖受限 |
| <25 | △ 探索 | "仅作方向性假设 / 需更多样本" | 仅单短文本或全探索维度 |

## 与既有纪律的衔接

- **原则 10 短文本分级**：CI 计算后若 `n=1` 且 `<300字`，强制 `CI≤25`（△探索）。
- **原则 5 重复模式优先**：C（一致性）直接量化"跨上下文重复"——C 低则即便单文本信号强，CI 也低。
- **原则 6 面具厚度加权**：M 因子把 `--multi` 的面具厚度指数转化为置信折减；有亲密语境样本时，对其结论可单独上调（关系语境 ×1.5，原则 12）。
- **△ 探索维度**（D3/D7/D21/D26-29/D35-40 等）：即便 CI 高，这些维度的结论仍须标注 △ 探索性（诚实边界）。

## 示例（示意，非真实测量）

**对象 A**：3 份文本（正式写作 1200字 + 意识流日记 800字 + 社交媒体 500字），`min=500≥300`，`n=3` → `S=0.8`。
Step 1 记录 40 条观察，36 条映射到场景 → `H=0.9`。
`d_scan --multi` 输出 `cv_by_dim` 均值 0.3（核心维）→ `C=1-0.3=0.7`；`mask_thickness=0.45` → `M=1-0.5×0.45=0.775`。
ND2↑ 已校准 → `N=0.9`。语域覆盖 3 类 → `R=1.0`。
`CI = 100×(0.30×0.8 + 0.20×0.9 + 0.20×0.7 + 0.15×0.775 + 0.10×0.9 + 0.05×1.0)`
`= 100×(0.24 + 0.18 + 0.14 + 0.116 + 0.09 + 0.05) = 100×0.816 = 81.6` → ■ 强。

**对象 B**：1 份公开博客 300字（精修），`n=1, min=300` → `S=0.45`。`H=0.5`。无 `--multi`（C 缺省按单文本 0.5）。`M=1`（无跨语境数据）。ND 无标记 `N=1.0`。语域 1 类 `R=0.6`。
`CI = 100×(0.135 + 0.10 + 0.10 + 0.15 + 0.10 + 0.05) = 100×0.635 = 63.5` → ● 中。
但注意：单公开博客且 `min=300` 恰在阈值，且 D3/D7/D26-40 等探索维度无法覆盖 → 即便 CI 中，对探索维度的结论须降级标注。这正是"朋友案例"的情形（详见下）。

## 与朋友案例的对应

朋友的输出显示"局限：样本全部来自公开博客的精修文本，不是即时私聊……仅 4 篇……D3/D7/D26-40 未充分覆盖，ND 层未见足够重复信号"——这恰是 CI 框架识别的**低置信情形**：

- `n=4` 但全为单一语域（公开博客）→ S 受语域单一限制，R 仅 0.6；
- 精修文本放大正式度 / 完美主义 → 需经 RCL 基线偏移（`rcl-baselines.md`）校正，否则 D15/D6 读数偏高；
- 探索维度 D3/D7/D26-40 无覆盖 → 这些维度即便算出来也须 △ 探索标注；
- ND 层无重复信号 → N 因子本应下调，但脚本未跑 ND 重复校验 → 输出主动声明"不予纳入结论"，符合诚实边界。

→ 结论：朋友看到的是 LPP 的**标准局限性自检文本**，不是"调成了仅限即时私聊扫描"模式（LPP 无此模式）。换用即时私聊 / 跨语域样本重跑，CI 与覆盖会显著回升。

## 生成方式

```bash
# 1) 跑跨语境面具厚度 + 一致性（同一人不同语境样本）
python scripts/d_scan.py --multi 样本1.txt 样本2.txt 样本3.txt --json
#    → 取 mask_thickness 与 cv_by_dim 填入 M / C
# 2) Step 1 记录 total 条观察、其中 mapped 条映射到场景 → 填 H
# 3) 按本文件六因子公式手算 CI，或用 LLM 基于上述数值直接给 CI 与四级
```
