# lpp-lsm 中文功能词表（探索性）

> lpp-lsm 参考词表 · 更新 2026-08-27 · 全部标注 △ 探索性——词表为启发式起点，非权威语言学资源；中文功能词研究远少于英文（LIWC 为英文词表），使用中按语料实际校准。

## 用途

lpp-lsm 的 S1（功能词分布）与 S4（填充词/话语标记）的计算依据。计算方式：统计双方文本中各词类的相对频率分布，比较分布相似度（非逐词命中率）。**匹配的是"分布形状"，不是"词有没有出现"**——两个人用词种类相近但比例不同，匹配度仍低。

## 一、代词

| 子类 | 词例 |
|------|------|
| 第一人称单数 | 我 |
| 第一人称复数 | 我们、咱们 |
| 第二人称 | 你、您、你们 |
| 第三人称 | 他、她、它、他们、她们 |
| 指示代词 | 这、那、这个、那个、这些、那些 |
| 疑问代词 | 什么、怎么、为什么、哪、谁 |

观察要点：我/你/我们 比例（呼应 LPP D8 人称平衡）；"咱们"（亲近标记）频率。

## 二、助词

| 子类 | 词例 |
|------|------|
| 结构助词 | 的、地、得 |
| 时态助词 | 了、着、过、正在 |
| 语气助词 | 的、了、吧、呢、吗、啊、呀、哦、嘛、哈 |

观察要点："的"字密度（修饰链长度）、"了"的完成标记频率、"吧/呢/吗"的疑问软化程度。

## 三、语气词（S2 核心）

| 类别 | 词例 |
|------|------|
| 疑问型 | 吗、呢、吧（求证） |
| 感叹型 | 啊、呀、哇、哈、哈哈 |
| 软化型 | 吧、嘛、哈、嗯 |
| 停顿型 | 嗯、呃、那个、怎么说呢 |

观察要点：语气词**谱**（种类集合）与**密度**（每百字次数）双指标——同频者两指标都接近。

## 四、连词

| 子类 | 词例 |
|------|------|
| 并列 | 和、跟、还有、以及 |
| 转折 | 但是、可是、不过、然而、其实（转折标记） |
| 因果 | 因为、所以、因此、既然 |
| 递进 | 而且、并且、甚至 |
| 条件 | 如果、假如、只要、除非 |

观察要点：转折词 vs 因果词的比例（呼应 LPP D12 因果链）；"但是/可是"偏好是风格指纹。

## 五、填充词/话语标记（S4 核心）

| 类别 | 词例 |
|------|------|
| 开启型 | 就、然后、就是说、怎么说呢、那个 |
| 犹豫型 | 嗯、呃、就是说、这个这个 |
| 确认型 | 对对对、是是是、没错、确实 |
| 反馈型 | 嗯嗯、好的、收到、哈哈（倾听回馈） |
| 口头禅型 | 其实、反正、确实、讲真、说实话 |

观察要点：话语标记密度高 = 口语化、即时性高；确认型标记（"对对对"）高 = 高认同回馈（S6 内容呼应的信号之一）。

## 六、程度副词（辅助）

| 类别 | 词例 |
|------|------|
| 绝对化 | 总是、从不、必须、完全、根本（呼应 LPP D10） |
| 软化 | 可能、大概、也许、应该、似乎（呼应 LPP D24） |
| 强调 | 真的、确实、特别、超、巨 |

观察要点：绝对化 vs 软化的比例分布——风格指纹之一；两人分布同向（都高绝对化或都高软化）= 同频。

## 七、介词与书面标记（v1.1 新增 · 2026-08-28）

> 补这两类的原因：初版词表偏口语，书面文本（"其/之/该/及"）命中率低导致"书面 vs 书面"误判为低同频。脚本与词表已同步更新。

| 类别 | 词例 |
|------|------|
| 介词 | 在、从、向、对、为、于、以、被、将、把、关于、对于 |
| 书面标记 | 其、之、该、及、亦、尚、已、欲、宜、若、诸、此、彼、皆、遂、颇 |

观察要点：介词密度 + 书面标记密度是"正式度"的强代理——书面 vs 口语的主要区分维度之一（配合 S1 密度调节使用）。

## 八、表情与颜文字（S2 扩展 · v1.2 新增 · 2026-08-28）

> 纯文本聊天里"语气"的一部分由表情/颜文字承载——并入 S2 语气标记密度（脚本已实现：语气词 + emoji unicode 范围 + 常见文本表情）。

| 类别 | 例 |
|------|-----|
| Emoji（unicode 范围） | 😀-🙏、😂-🫶、❤️🔥 等（脚本用 unicode 范围匹配） |
| 文本表情 | :)、:-)、:-(、^_^、T_T、QAQ、233、hhh、wwww |
| 叠字笑声 | 哈哈哈哈、哈哈哈（脚本归入 TEXT_EMOJI 简化处理） |

观察要点：表情密度高 = 情绪显性度高的语气；双方表情使用模式（大量 vs 零）本身就是语气同频信号。

## 九、消息节奏（S9 · v1.2 新增 · 仅对话模式）

聊天文本的节奏不以"句"为单位，以**消息**为单位：
- 消息长度（一条发几个字 vs 一坨长文）
- 消息内句数（一句话一条 vs 多句拼一条 = 分段习惯）
- 发送间隔模式（若时间戳存在：`[21:00] A: xxx`——双方各自的发送急促/从容程度）

观察要点：消息长度分布的均值和变异系数是聊天节奏指纹；脚本 S9 在对话模式自动激活（S3 10% / S9 10%）。

## 十、句末标点与节奏代理（S3 辅助）

| 标记 | 观察 |
|------|------|
| 句号密度 | 断句频率（一逗到底 vs 短促成句） |
| 感叹号密度 | 情绪显性度 |
| 省略号 | 欲言又止/留白偏好 |
| 问号密度 | 提问型 vs 陈述型互动 |

## 使用注意

1. **分布相似度 > 逐词命中**：用词类相对频率（如"每百字"归一化）比较。
2. **文体归一化**：正式写作语气词近零——先用 `lpp-register` 校准再比（跨文体对比无意义）。
3. **方言/网络语**：语气词受地域（东北"咋/搁"、粤语"咩/啦"）与世代（网络语气词）影响——结合 `lpp-geo`/`lpp-glm` 排除（参照 LPP 方言校正原则）。
4. **词表验证状态**：△ 探索性——本表为 lpp-lsm v1.0 自建起点，尚未经真实语料基准测试；后续可用真实对话语料迭代（如"对账 10 组高/低同频对话，校准权重"）。v1.2 已补介词/书面标记（S1 密度调节）、表情（S2）、消息节奏（S9）。
