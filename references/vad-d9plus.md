## 1. 原理

D9（情绪词汇）当前统计"情绪词总量 + 正负效价比"。VAD 将每个词映射到三维连续空间：

| 维度 | 含义 | 0 → 1 |
|------|------|-------|
| **V** (Valence) | 效价 | 极负面 → 极正面 |
| **A** (Arousal) | 唤醒度 | 极平静 → 极激动 |
| **D** (Dominance) | 支配感 | 极无力 → 极掌控 |

**两层输出**：
1. **VAD 聚合坐标**（V_μ, A_μ, D_μ）— 文本整体情绪倾向
2. **最近邻情绪词**（VAD 空间直接最近邻）— 精确情绪标签，替代 6 类分桶

**D 维度的 LPP 关键价值**：D8（人称标记）、D15（正式度/敬语）、D17（归因风格）、D21（表达节奏）都隐含支配度信号。VAD 提供的词级 D 值可以与这些语言模式-D 做一致性检查——一致说明人格与情绪统一，背离说明存在面具/伪装。

## 3. 信号解读

### 3.1 VAD 聚合坐标 → D9 交叉

| VAD 信号 | D9 交叉 | LPP 解读 |
|----------|---------|---------|
| V_μ < 0.4 | D9 负面词占比高 | 整体负面情绪基调，对照 N（情绪性）维度 |
| V_μ > 0.6 | D9 正面词占比高 | 整体正面情绪基调 |
| A_μ > 0.6 | D9 情绪词密度高 | 高唤醒——活跃/激动而非平静 |
| A_μ < 0.35 | D9 情绪词密度低 | 低唤醒——平静/抑制 |
| V_σ 高 | D9 正负词均有 | 情绪波动大，情境敏感 |
| V_σ 低 | D9 正负比稳定 | 情绪稳定，基调一致 |

**不用手写阈值做人格映射**：VAD 信号不直接映射到大七/大五维度。D9+ 的使命是提供客观的情绪量化数据，人格归纳由 Step 3 的 D 维度体系完成。VAD 的 V_μ/A_μ/D_μ 作为 Step 3 的输入证据，与 D9/D20/D5/D11 并列。

### 3.2 最近邻情绪词 — 精确情绪标签

这是 VAD 的核心精度增益。不使用 6 类情绪分桶（如"恐惧""悲伤"），而是直接在 ~110 个情绪描述词的 VAD 空间中找最近邻：

- 文本 VAD = (0.41, 0.43, 0.44) → 最近邻: **ambivalent** (矛盾), **drained** (耗竭), **wistful** (惆怅)
- 文本 VAD = (0.65, 0.48, 0.69) → 最近邻: **determined** (坚定), **reverent** (敬畏), **confident** (自信)

这些词直接进入报告，作为精确的情绪画像标签。

### 3.3 D 一致性检查 — VAD-D vs 语言模式-D

LPP 有多条 D 维度观察通道携带支配度信号：

| 语言模式 | 低 D 信号 | 高 D 信号 |
|---------|----------|----------|
| D8 人称标记 | "我"高频，"你/我们"低频 → 自我沉溺/社交无力 | "我们"高频，"你/你们"清晰 → 关系中的主导性 |
| D15 正式度 | 过低（不规范）或过高（过度补偿）→ 位置焦虑 | 跨语境适度 → 掌控自如 |
| D17 归因风格 | 外归因（"因为别人/环境"）→ 无力感 | 内归因（"因为我做了X"）→ 掌控感 |
| D21 表达节奏 | 断裂句多，停顿失控 → 节奏被情绪打乱 | 节奏稳定，长短句有控制 → 主动调度 |

**检查方法**：
1. 从 VAD 取文本 D_μ（词级支配度均值）
2. 从 Step 1 的 D8/D15/D17/D21 观察中提取语言模式-D 倾向
3. 对比两者：

| 情况 | 信号 | 解读 |
|------|------|------|
| VAD-D 与语言-D 一致（都低/都高） | 人格-情绪统一 | 词级情绪和语言模式指向同一方向，信号可靠 |
| VAD-D 低 + 语言-D 高 | D 背离 | 语言层面有掌控感，但用词透露无力——可能面具/防御 |
| VAD-D 高 + 语言-D 低 | D 背离 | 用词强势但语言模式被动——可能外强中干 |

> D 背离本身是人格分析信号——指向可能的 self-presentation 与内在体验的不一致。在 Step 3 中标注为"D张力"，作为置信度调制参考。

## 4. 段落级 VAD 轨迹（LPP 独有）

对文本按段落切分，计算每个段落的 V_μ/A_μ/D_μ，观察时间序列。与 D 维度情绪轨迹互补：

| 轨迹模式 | 信号 |
|---------|------|
| V↑ D↓ | 表面情绪好转但掌控感流失——"勉强乐观" |
| V↓ A↑ | 效价下降且是高唤醒（愤怒/焦虑而非悲伤） |
| V平 A↓ D↓ | 情绪在"熄灭"——可能的解离性扁平化 |
| V波动 D稳定 | 情绪起伏但掌控感不受影响——高情绪调节能力 |
| D全程低 + A全程高 | 持续的高唤醒无力感——焦虑型基调 |

用于 Step 3 交叉验证：情绪轨迹（1D V）与 VAD 轨迹（3D）一致 → 信号增强；不一致 → 标注分歧。

  restless  ██████████ (活跃但不安)

  drained   █████    (耗竭)

  D9: 负面词22% → 与V_μ=0.62一致（整体偏正面但负面不低）

  前段: V_μ=0.58 A_μ=0.75 D_μ=0.40 → 高唤醒，中低效价

  → "前段焦虑→中段爆发→后段收束"的波动路径，收束段D回升提示存在自我调节能力
