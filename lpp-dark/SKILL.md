# lpp-dark — 暗黑人格检测

> LPP 言灵包子技能 · △ 探索性层

## 概述

暗黑人格（Dark Tetrad）是大五/大七人格模型的互补层——A（宜人性）/R（人际关系）低分端不能完全覆盖其独特变异。LPP 使用 D26-D29 的观察结果做探索性归纳。

## 检测逻辑

D26-D29 不属于稳定模式的重复模式判断，而是**极端标记检测**——只要在文本中出现就值得注意，但**不能仅凭一个标记下定论**：

| 观察模式 | 可能的指向 | 最低启动条件 | 置信度 |
|---------|----------|------------|-------|
| D26 高频（幸灾乐祸）+ D28 高频（共情空洞） | 施虐倾向/冷酷特质 | ≥3 处原文引用，跨语境 | ▲ 弱 |
| D27 高频（工具人称）+ 人称失衡 | 马基雅维利主义（操控性） | ≥5 处原文引用 | ▲ 弱 |
| D29 极端（归因两极）+ D10 高频（绝对化） | 自恋型归因风格 | 跨语境一致模式 | ▲ 弱 |
| D28 高频 + D9 极低（情绪词稀疏） | 情感冷漠/述情障碍 | 结合 D9 观察 | △ 探索 |

### 相关 D 维度

| D# | 维度 | 观察重点 |
|----|------|---------|
| D26 | 施虐/幸灾乐祸词汇 | "活该/真惨哈哈哈"类话语在他人负面事件语境中的频率 |
| D27 | 工具性人称模式 | 人称代词用于工具性目的——"你帮我""给我""你要" |
| D28 | 共情空洞标记 | 他人痛苦语境下无情绪词、使用分析距离、迅速转移话题 |
| D29 | 优越归因模式 | 成功 100% 内归因 + 失败 100% 外归因的极端模式 |

## 输出格式

```
─── 暗黑人格检测（△ 探索性 — 基于D26-D29）───

├─ 施虐/幸灾乐祸倾向：[未观察到 / 有限证据提示 / 不排除……可能性]
├─ 工具性人称模式：[未观察到 / 有限证据提示 / 不排除……可能性]
├─ 共情空洞：[未观察到 / 有限证据提示 / 不排除……可能性]
├─ 优越归因模式：[未观察到 / 有限证据提示 / 不排除……可能性]
└─ ⚠️ 本分析不能替代专业心理评估
```

## 重要限制

- 暗黑人格**不能从语言模式可靠诊断**——LPP 仅标记"值得留意的一致模式"
- 单次类似表达可能只是情境幽默，不是人格特质——需 ≥3 处跨语境引用
- 暗黑人格高分者可能在语言中刻意掩饰，降低检测灵敏度
- 所有输出必须标注"△ 探索性"和伦理提示
