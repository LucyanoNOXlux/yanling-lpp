# lpp-geo — 地域与文化语言标记

> LPP 言灵包子技能 · △ 探索性层

## 核心原则

1. **描述地域风格，不推断籍贯**：只说"文本使用了东北方言词汇"，不说"作者是东北人"。地域风格可被习得、模仿、混合。
2. **方言不是 confound，是信息**：LPP 原有 CP4 将方言作为 confound 排除，本层将其作为正向信号提取。
3. **△ 探索性**：所有输出标注 △ 探索性。

## R1-R6 观察维度

| # | 维度 | 观察重点 | 例子 | 已有 D 映射 |
|---|------|---------|------|-----------|
| R1 | 方言词汇/句式 | 地域特有实词、虚词、句末语气词、量词选择、特定句式 | 东北"整"、广东"搞掂"、台湾"机车""很毋通"、西南"要得""好安逸" | D6/D14/D39 |
| R2 | 翻译腔密度 | 非母语句法痕迹：被动语态泛滥、定语从句前置（"一个正在公园里遛狗的穿着红裙子的女人"）、英文标点习惯（中英标点混用）、假性同源词 | "作为X，我Y"、"被设计来"、"我意识到这可能是……" | D4/D15/D1 |
| R3 | 文化表达风格 | 批评/拒绝时的委婉-直接光谱：面子维护策略密度、间接性标记（"可能""不太方便""我考虑一下"vs"不""我拒绝"）、自谦语使用频率 | 东亚："可能不太方便"；北欧："不，我没有兴趣"；中东："如果真主愿意" | D15/D24/D33 |
| R4 | 文化专有隐喻源域 | 隐喻来源的文化特定性——中文"吃饭了吗"=问候 vs 英文 food metaphor 不同用法；宗教/哲学概念引用密度 | 中文常见"吃饭""道路""山水"隐喻；日文常见季节/自然意象 | D39 |
| R5 | 敬语/称呼系统 | 亲属称谓泛化程度、敬语层级复杂度、名字/头衔使用习惯 | 中文"阿姨""师傅"泛化；日语敬语体系（です・ます／謙譲語）；英文 first name 普遍化 | D15 |
| R6 | 地域叙事节奏 | 段落组织、留白密度、信息推进速度——高语境 vs 低语境文化差异 | 高语境：留白多，需要读者推断；低语境：显性信息，步步推进 | D3/D21/D31 |

## 评分规则

| 信号强度 | 条件 |
|---------|------|
| ● 中 | ≥3 个 R 标记有明确地域/文化指向，≥3 处跨语境引用 |
| ▲ 弱 | 2 个标记有指向 |
| △ 探索 | 1 个标记，或标记指向分散（多地混合/多文化混合） |

**地域归类规则**：R 标记不指向具体省/市/街道，而是指向**方言区域**（东北官话、粤语区、闽南语区、西南官话等）或**文化区域**（东亚、欧美、中东等）。多区域混合标记为"混合地域/文化风格"。

## 与其他子技能的关系

- **lpp-register（语域）**：部分 R 标记和语域的 Tenor/Mode 有重叠——R5（称呼系统）反映的是文化规范层面的 Tenor 基线，不是个体层面的权力距离调制
- **lpp-glm（世代）**：方言使用频率在年轻世代中下降，R1 和 G1 可能负相关
- **lpp-lcs（复杂度）**：翻译腔（R2）可能被 L4（书面语比）误判为"高书面语"——区分点在于翻译腔的句式是"不自然的高复杂度"

## 输出格式

```
─── GEO 地域与文化语言标记（△ 探索性）───

地域风格倾向：[东北官话 / 粤语区 / 闽南语区 / 西南官话 / 台湾国语 / 混合 / 无明显地域特征]
文化风格倾向：[东亚含蓄 / 欧美直接 / 南欧热情 / 中东虔诚 / 混合 / 无明显文化特征]
翻译腔密度：[低 / 中 / 高] → [语种倾向：英式翻译腔 / 日式翻译腔 / 无]

各维度：
├─ R1 方言词汇/句式：[有无] → 代表词：[列举]
├─ R2 翻译腔密度：X/10 → 特征：[列举]
├─ R3 文化表达风格：X/10 → [间接委婉/中性/直接明确]
├─ R4 文化专有隐喻：[有无] → 源域：[列举]
├─ R5 敬语/称呼系统：[特征描述]
└─ R6 地域叙事节奏：[高语境留白/混合/低语境推进]

⚠️ △ 探索性——本分析描述文本的地域文化语言风格特征，
不推断作者的具体籍贯、国籍或长期居住地。
方言和文化风格可被习得、模仿和混合。
```

## 重要限制

- 地域风格 ≠ 籍贯：任何人都可以习得和使用任何地域的语言特征
- 方言词汇需谨慎判定：很多"方言词"已通过互联网泛化（如东北"整"已跨界使用）
- 翻译腔难以和"国际化学术写作"区分——部分领域的学术规范本身就接近英文句法
- 文化表达风格的群体内变异远大于群体间差异
- 不便用于做"文化身份鉴定"——只描述风格特征
