# lpp-lcs — 语言复杂度风格

> LPP 言灵包子技能 · △ 探索性层

## 核心原则

1. **描述复杂度，不推断教育/阶层**：只说"文本词汇多样性高、从句嵌套深"，不说"作者受过高等教育"。语言复杂度受多因素影响（阅读量、写作练习、专业领域、二语背景），不等于教育水平或社会经济地位。
2. **语域校准前置**：学术论文天然复杂度高——先扣除语域基线，再分析风格残差。
3. **△ 探索性**：所有输出标注 △ 探索性。

## L1-L6 观察维度

| # | 维度 | 低复杂度端（1-3） | 中复杂度端（4-7） | 高复杂度端（8-10） | 已有 D 映射 |
|---|------|-----------------|-----------------|-----------------|-----------|
| L1 | 词汇多样性（TTR） | 型符比低，高频词复用多，基础词汇占主导 | 中等词汇多样性 | 型符比高，罕见词、专业词汇密度大 | D14 |
| L2 | 句法复杂度 | 简单句为主，少从句，并列连接（"然后""还有"）为主 | 少量从句嵌套（1-2层） | 多层从句嵌套（≥3层），主从复合句为主 | D4 |
| L3 | 抽象词密度 | 具象名词为主（"桌子""吃饭""生气"） | 混合 | 抽象名词高频（"结构性""动力学""认知框架"） | — |
| L4 | 书面语-口语比 | 口语化（短句、语气词、省略、口语词汇） | 半书面（博客/邮件级别） | 高度书面（学术/公文级别） | D15 |
| L5 | 逻辑连接词复杂度 | 时序连接为主（"先""然后""最后"） | 因果连接（"因为""所以"） | 多类型逻辑连接（因果+让步+条件+对比混用） | D12 |
| L6 | 信息压缩度 | 低密度（一句话一个信息点） | 中等 | 高密度（名词化、前置定语、"的"字结构嵌套压缩多信息） | D22 |

## 评分规则

| 信号强度 | 条件 |
|---------|------|
| ● 中 | ≥4 个 L 标记方向一致，≥3 处跨语境引用 |
| ▲ 弱 | 2-3 个标记方向一致 |
| △ 探索 | 1 个方向标记，或 L 标记方向分散 |

语域校准：先按 RCL 画像扣除语域基线（如学术论文 L2/L4/L5 基线天然偏高），在残差上做复杂度判断。

## 与其他子技能的关系

- **PCS**：职业风格影响复杂度基线（法律/学术 ≥ 日常/新闻）
- **GLE**：语言复杂度可能和性别化语言表达有交互（如女性化风格 + 高复杂度 → 打破刻板印象）
- **GLM**（世代语言标记）：年轻世代的高信息压缩度（L6）可能来自网络文化而非"高复杂度"

## 输出格式

```
─── LCS 语言复杂度风格（△ 探索性）───

语域校准：已应用（Field专=X, Mode书=X）

整体复杂度：[低 / 中低 / 中 / 中高 / 高]  【▲弱/△探索】

各维度：
├─ L1 词汇多样性：X/10 → [低/中/高]
├─ L2 句法复杂度：X/10 → [低/中/高]
├─ L3 抽象词密度：X/10 → [低/中/高]
├─ L4 书面语-口语比：X/10 → [偏口语/半书面/偏书面]
├─ L5 逻辑连接复杂度：X/10 → [时序为主/因果/多类型]
└─ L6 信息压缩度：X/10 → [低/中/高]

⚠️ △ 探索性——本分析描述文本的语言复杂度风格特征，
不推断作者的教育水平或社会经济地位。
```

## 重要限制

- 语言复杂度 ≠ 智力或教育水平——大量因素影响（阅读习惯、专业领域、写作频率、二语影响、语境需求）
- 虚假复杂度：刻意使用生僻词和复杂句式 ≠ 高质量的复杂表达
- 体裁特定性：诗歌/歌词/广告文案的低复杂度（刻意凝练）不反映语言能力
- 跨语言不可比：中文的复杂度指标不直接等同于英文的同类指标
