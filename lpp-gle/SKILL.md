# lpp-gle — 性别化语言表达

> LPP 言灵包子技能 · △ 探索性层

## 核心原则

1. **描述风格，不推断身份**：只说"文本使用了更多 X 类语言模式"，不说"作者是 X"
2. **不挂钩性取向**：不做任何性取向推断
3. **文化相对性**：性别化语言规范因文化/时代/社群而异
4. **△ 探索性**：所有输出必须标注 △ 探索性

## G1-G8 观察维度

| # | 维度 | 偏女性化风格 | 偏男性化风格 | D 映射 |
|---|------|------------|------------|--------|
| G1 | 情感表达密度 | 高频情绪词、内感受描述 | 情绪词稀疏，外化行动替代 | D9 |
| G2 | 模糊限制语 | 高频 hedging（"可能""有点"） | 低 hedging，断言式表达 | D24 |
| G3 | 强势语/加强语 | 低频绝对化，协商式 | 高频绝对化、断言、命令式 | D10 |
| G4 | 人际取向标记 | 高频关系维护、共情表达 | 低频关系标记，任务导向 | D8 |
| G5 | 自我指涉模式 | "我"用于内省和情绪 | "我"用于行动和主张 | D8/D37 |
| G6 | 叙事细节类型 | 感官、人际关系、外貌细节 | 空间/技术细节、因果链 | D31 |
| G7 | 疑问句功能 | 邀请参与、关系维护 | 信息获取、挑战、反问 | D33 |
| G8 | 完结行为风格 | 仪式收束、情感总结 | 事实总结、行动收束、或截断 | D32 |

## 评分规则

| 信号强度 | 条件 |
|---------|------|
| ● 中 | ≥4 个 G 标记方向一致，≥3 处跨语境引用 |
| ▲ 弱 | 2-3 个标记方向一致 |
| △ 探索 | 1-2 个单方向标记，或方向混合不一致 |

方向判断：某一方向的标记数 ≥ 总标记数 60% → "偏该方向"；否则 "混合/中和"。

## 输出格式

```
─── GLE 性别化语言表达（△ 探索性）───

语言风格倾向：[偏女性化 / 偏男性化 / 中和混合]  【▲弱/△探索】

关键模式：
├─ G1（情感表达密度）：[观察] → [方向]
├─ G2（模糊限制语）：[观察] → [方向]
└─ [其他激活标记]

⚠️ △ 探索性——本分析描述文本的语言风格特征，不推断
作者的性别认同或性取向。
```

## 重要限制

- 社群亚文化 confound（同人圈、游戏圈等有独立语言风格）
- 语域 calibrate 前置：不加语域校准，学术写作的"低情感表达"可能被误判为偏男性化
- 时代敏感性高（18 个月复查性别化语言规范变化）
