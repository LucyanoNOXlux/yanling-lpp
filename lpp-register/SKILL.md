# lpp-register — 语域分析

> LPP 言灵包子技能 · 预分析基础层

## 概述

基于系统功能语言学（Halliday）的语域理论，对文本做三维画像，描述"语言在什么情境下被使用"——不推断作者身份，只分析情境特征。

## 三维语域画像

| 维度 | 光谱（1-10） | 低端（1-3） | 中端（4-7） | 高端（8-10） |
|------|------------|-----------|-----------|------------|
| **Field · 专业化** | 日常→专业 | 闲聊、生活话题 | 科普、半专业讨论 | 学术论文、技术文档 |
| **Field · 话题范围** | 窄→宽 | 单一主题 | 2-3个相关主题 | 多主题跳跃 |
| **Tenor · 权力距离** | 平等→等级 | 朋友、匿名社交 | 同事、半正式 | 上下级、机构声明 |
| **Tenor · 情感距离** | 亲密→疏远 | 伴侣/家人、自剖 | 社群互动 | 公众演讲、陌生人 |
| **Mode · 口语-书面** | 口语→书面 | 即时聊天、弹幕 | 博客、邮件 | 论文、公文 |
| **Mode · 互动性** | 独白→对话 | 日记、观点文章 | 半对话（隐含读者） | 群聊、辩论、访谈 |

## 输出格式

```
─── 语域画像 ───

Field 专业化：7/10（半专业科普讨论）
Field 话题范围：3/10（单一主题贯穿）
Tenor 权力距离：5/10（作者-读者平视）
Tenor 情感距离：6/10（公共表达但有个人温度）
Mode 口语-书面：7/10（精修议论文）
Mode 互动性：2/10（独白式论证，偶有设问）

综合判断：[场合描述，如"面向公众的科普性议论文"]
```

## 语域作为 LPP 预分析层

在 LPP 全流程中，语域画像用于校准所有 D 维度的基线期望值——确保 Step 1 观察到的语言模式差异反映人格差异而非情境差异。

### 语域→D维度校准

| 语域光谱↑ | D维度基线↑ | D维度基线↓ |
|-----------|-----------|-----------|
| Field 专业↑ | D14（精确度）、D15（正式度）、D12（因果链） | D6（语气词）、D25（填充词）、D9（情绪词） |
| Tenor 权力距↑ | D15（正式度） | D6、D33（开放式提问） |
| Tenor 情感距↑ | D15（正式度） | D9、D8"我"（内省）、D5（断裂句） |
| Mode 书面↑ | D4（句长）、D12、D1（标点） | D5、D25、D6 |
| Mode 互动↑ | D33（提问）、D8"你/你们"、D6 | D4、D13（话题聚焦） |

校准公式：`D_n 校正值 = D_n 原始值 - 语域基线偏移(n)`

### 语域背离检测（探索性）

- Field 专业 + Mode 口语（聊天语气讲学术）→ 刻意亲近受众
- Tenor 亲密 + Mode 书面（情书写成论文）→ 情感表达的防御性距离
- 语域切换作为情绪调节：正文中正式度突然断裂（从论证语域掉到口语碎片）→ 情绪破防

### 权力敏感度增强（LPP T 维度）

语域画像可以独立验证大七 T（处世态度）——这是 LPP 证据最薄弱的维度。逻辑：

```
Tenor 权力距离在不同对象间的调制幅度 → T 维度信号

高调制（对上级 9/10，对平级 4/10）→ T 偏功利/争强好胜
  └─ 策略性地使用语言权力——知道什么时候该"端"，什么时候该"放"

低调制（始终 4-6 区间）→ T 偏淡泊/随遇而安
  └─ 权力距离稳定，不因对象等级变化而调整语言策略
```

**检测条件**：需要同一作者在不同 Tenor 语境下的多份文本（≥2 份，每份 ≥200 字）。单文本无法做此分析。

**与核心 Step 3 的集成**：输出为 T 维度的辅助增强信号——与场景定位的 T 信号方向一致时增强置信度；方向冲突时标注"语域信号与场景信号不一致，T 维度置信度降一级"。

**限制**：
- 仅适用多文本跨语境分析，单文本激活条件不满足时标注"多文本不足，权力敏感度跳过"
- Tenor 调制可能受职业规范驱动（如服务行业对所有客户保持统一正式度），不一定是人格信号
- 需要先区分"策略性调制"（有意识）vs"适应性调制"（无意识模仿）——但目前语言模式难以区分两者

## 其他应用场景

| 场景 | 用途 |
|------|------|
| 社交动态分析 | 谁在对话中主导？权力距离随发言人如何变化 |
| 平台适配度 | 同一个人在不同平台会不会切换语域 |
| 关系阶段推断 | 对话语域从 Tenor 高+Modes书面 → Tenor 平等+Mode 口语 |
| AI 生成检测（辅助） | LLM 语域偏"均衡"，真实人类切换更突兀 |
| 组织文化诊断 | 内部文档的语域反映企业文化 |

## 限制

- 不推断作者职业/身份/性别/性取向
- 同一个人在不同语域中语言模式可能截然不同
- 社群亚文化可能发展出独立于主流规范的语域
