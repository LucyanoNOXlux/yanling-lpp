# lpp-glm — 世代语言标记

> LPP 言灵包子技能 · △ 探索性层

## 核心原则

1. **描述世代风格，不推断年龄**：只说"文本使用 2020 年代网络用语"，不说"作者 25 岁"。同一世代内部的语言风格差异极大，且任何年龄的人都可以使用任何世代的表达方式。
2. **时间锚点，非身份标签**：GLM 探测的是"这段文本在语言时间轴上落在哪个区间"——它离当下的互联网有多近。
3. **△ 探索性**：所有输出标注 △ 探索性。网络用语词表时效性强（每 6 个月复查更新）。

## G1-G5 观察维度

| # | 维度 | 传统世代特征（1-3） | 过渡世代特征（4-7） | 新兴世代特征（8-10） | 已有 D 映射 |
|---|------|-------------------|-------------------|-------------------|-----------|
| G1 | 网络用语/流行语密度 | 极少或无（"同志""网友""博客"等旧网络词汇） | 中等（通用网络用语，如"内卷""躺平""破防"） | 高密度 + 高时效（当年热词，如 2025-2026 流行语） | D25b |
| G2 | 语法风格代际特征 | 传统语法严谨（书面语规范、完整句式） | 混合（适度省略，接受口语化书面表达） | 解构式语法（刻意不规范、语气词替代表达、标点情绪化、"…"和"。"的情绪功能分化） | D1/D2/D5 |
| G3 | 文化引用时间锚点 | 引用经典文学、老歌、早期互联网梗 | 引用 2010s 流行文化、中期互联网亚文化 | 引用当前流行文化、游戏/二次元/短视频平台热梗 | D34 |
| G4 | 省略与信息压缩 | 完整表达，避免歧义省略 | 适度省略 | 极限压缩（"笑死""谁懂""我：……"等省略到需要共享语境才能解码） | D22/D38 |
| G5 | 情感表达代际特征 | 含蓄表达（"颇为""不甚""尚可"），情绪词严谨 | 混合 | 外显+夸张表达（"我哭死""好绝""天哪"），情绪词高频且强度极化 | D9/D10 |

## 词表时效性规则

G1 的"当前热词"判定基于词表日期：

```
词表日期：2026-07-19（每 6 个月复查更新）
当前热词参考：2025-2026 年中文互联网高频流行语
旧网络词汇参考：2015 年前流行的网络用语
```

分析时标注词表日期。超过 6 个月未更新的词表，G1 置信度降一级。

## 评分规则

| 信号强度 | 条件 |
|---------|------|
| ● 中 | ≥3 个 G 标记方向一致指向同一世代区间，≥3 处跨语境引用 |
| ▲ 弱 | 2 个标记方向一致 |
| △ 探索 | 1 个标记，或标记分散（混合世代风格） |

**世代区间映射**：
- G1-G5 均值 1-3 → 传统世代语言风格（约 2010 前互联网或更早）
- 均值 4-7 → 过渡世代（约 2010-2020 互联网）
- 均值 8-10 → 新兴世代（约 2020 后互联网）
- 混合 → 可能跨世代语码切换

## 与其他子技能的关系

- **D25b**：GLM 是 D25b 的独立升级版，D25b 现在降为 GLM 的子引用
- **LCS（语言复杂度）**：年轻人的极限压缩（G4↑）可能被 L6（信息压缩度）误判为"高复杂度"——但压缩方式不同：年轻世代是省略+共享语境，学术写作是名词化+嵌套
- **GLE**：网络用语的性别化分布（如某些热词在特定性别群体中使用频率显著不同）
- **PCS**：特定职业的世代语言特征（互联网公司的内部沟通比传统行业世代特征更新）

## 输出格式

```
─── GLM 世代语言标记（△ 探索性）───

词表日期：2026-07-19

世代风格倾向：[传统世代 / 过渡世代 / 新兴世代 / 混合]  【▲弱/△探索】

各维度：
├─ G1 网络用语密度：X/10 → 代表词：[列举3-5个]
├─ G2 语法风格：X/10 → [传统严谨/混合/解构式]
├─ G3 文化引用锚点：X/10 → 代表引用：[列举]
├─ G4 省略与信息压缩：X/10 → [完整表达/适度省略/极限压缩]
└─ G5 情感表达代际特征：X/10 → [含蓄/混合/外显夸张]

⚠️ △ 探索性——本分析描述文本的世代语言风格特征，
不推断作者的具体年龄。同一世代内部语言风格差异极大。
词表日期：[日期]，每 6 个月复查更新。
```

## 重要限制

- 世代语言风格 ≠ 年龄：任何年龄都可以使用任何世代的表达方式
- 社群/亚文化 confound：同人圈、游戏圈等有独立于主流世代标尺的语言演化速度
- 网络用语的"潮汐效应"：一个热词可能在 3 个月内从"新锐"变成"过时"，时间锚点精度有限
- 跨平台差异：B站/小红书/知乎/微博的语言世代标尺不同，GLM 默认校准为微博/综合社交平台
- 词表时效性衰减快：G1 置信度随词表老化线性衰减
