# lpp-cogstyle — 认知风格语言标记

> LPP 言灵包子技能 · △ 探索性层

## 概述

本子技能识别文本里**系统化（systematizing）的加工方向**。理科生思维与 ASD 思维都高度系统化，但方向相反：

- **理科生思维**：系统化 → 向上压缩成框架（归纳模型、找底层逻辑、降维）
- **ASD思维**：系统化 → 向下穷尽细节（忠实归档、拒绝压缩、按事实等权重）
- **混合态**：两套系统同时在线，呈**双层结构**——底层 ASD 档案 + 上层理科生可部署壳，且说话人**知道缝在哪**

判别不看"有没有系统化"，看"系统化指向哪个方向"。

## 核心原则

1. **描述认知风格，不推断神经诊断**：只说"文本呈现 X 类系统化方向"，不说"作者是 ASD/理科生"。ASD 是谱系+临床诊断，本分析是概率性语言倾向。
2. **与 ND 层互补**：`Step 1.5 ND2（系统化加工标记）`判断"此模式是否可能源于 ND 认知"；本技能进一步判断"系统化朝哪个方向"。ND 问来源，cogstyle 问方向。
3. **重叠常态**：纯态少见，混合态（神经多样 + STEM 训练）是真实常态。
4. **△ 探索性**：所有输出标注 △ 探索性。

## C1-C9 观察维度

| # | 维度 | 观察要点 |
|---|------|---------|
| C1 | 抽象方向 | 向上建模型/归纳框架（"底层逻辑"） vs 向下扎根/穷尽事实/拒绝压缩 |
| C2 | 比喻使用 | 学科比喻作桥梁（"像熵增/benchmark"） vs 少用、用则显式标注"打个比方" vs 感官型个人隐喻 |
| C3 | 信息排序 | 按重要性/逻辑层级、先框架后细节 vs 细节等权重、按记忆涌现（闪回） |
| C4 | 总结倾向 | 必总结升华（"总之本质是…"） vs 抗拒总结（"总结=失真"） vs 看情况可选 |
| C5 | 听众适配 | 天然 teacher mode 向下兼容 vs 常缺、按自己架构原样输出 vs 能部署但知是"壳" |
| C6 | 叙事弧 | 问题→分析→结论（标准弧） vs 无标准弧、一件事想起下一件 vs teacher↔raw 同文本交替 |
| C7 | 情感标注 | 情感词做修辞/说服 vs 零标注纯陈述或显式"我感到X" vs 多 + 自我监控元评论 |
| C8 | 特殊兴趣 | 兴趣广、切换快 vs 某话题极细展开超出所需 vs 深度型框架（从自身兴趣长出） |
| C9 | 句式特征 | 条件句密集（"如果…那么""在XX条件下"） vs 陈述/枚举密集（"XX说…"刻板重复） vs 精确术语+感官细节混排 |

## 三态判别表

| 判别点 | 纯理科生 | 纯 ASD | 混合态 |
|--------|---------|--------|--------|
| 原始档案层 | 无，直接压缩 | 仅有，拒绝压缩 | 两者皆有 |
| teacher mode | 天然、无痛 | 难维持/不会 | 能部署，但知是壳 |
| 比喻 | 学科桥梁多 | 少，用则标注 | 有，感官型个人隐喻 |
| 元评论（自我观察） | 少 | 少 | 多（"我社会化满级了"） |
| 框架来源 | 通用模型 | 无框架 | 特殊兴趣深度型 |
| 切换可见性 | — | — | 有缝，且自知 |

## 混合态双层模型（关键判别）

混合态不是"中和"，是**双层结构**：

- **底层**：ASD 的忠实档案（事实等权重、闪回、不总结）
- **上层**：理科生的可部署壳（框架、teacher、降维）

**判别 tell 在"缝"上**：
- 纯理科生：看不到底层，全程框架
- 纯 ASD：看不到上层，全程 raw
- **混合态：两层都露出来，且说话人知道缝在哪**（如"坦坦荡荡地冷漠"= 主动掀壳）

实操判别法：给同一段经历——
- 理科生先给结论/框架，再补细节，"总之就是 XX"
- ASD 先堆事实，不主动给结论；你问"所以呢"，ta 可能答"就是这些事"
- 混合态：两段都写得出，且能说明自己在哪层

## 评分规则

| 信号强度 | 条件 |
|---------|------|
| ● 中 | ≥5 个 C 标记方向一致，且能定位到单一态或确认混合态双层 |
| ▲ 弱 | 3-4 个标记方向一致 |
| △ 探索 | 1-2 个单方向标记，或方向混合无法判定 |

方向判定：某态标记数 ≥ 总标记数 60% → "偏该态"；否则 "混合/未定"。

## 输出格式

```
─── 认知风格语言标记（△ 探索性）───

系统化方向：[理科生思维 / ASD思维 / 混合态]  【▲弱/△探索】

关键模式：
├─ C1（抽象方向）：[观察] → [方向]
├─ C3（信息排序）：[观察] → [方向]
├─ C5（听众适配）：[观察] → [方向]
└─ [其他激活标记]

态判定：[纯理科生/纯ASD/混合态] + 依据
混合态缝检：可见缝 / 不可见 / 说话人自知缝位置

⚠️ △ 探索性——本分析描述文本的系统化语言方向，
不推断作者的神经类型或临床诊断。
```

## 重要限制

- **非诊断**：ASD 是谱系+临床诊断概念，本技能输出概率性语言倾向，不是诊断标准。
- **重叠区大**："理科生有阿斯伯格特质"（geek syndrome）已被观察，重叠区正常。判的是方向，不是"有没有系统化"。
- **语域校准前置**：学术写作的"向上框架"可能是文体要求，非认知风格——先做 `lpp-register` 校准。
- **文化偏倚**：STEM 比喻密度受专业/时代影响；中文语境"理科生"含意与欧美不同。
- **面具厚度**：混合态的上层壳可能是刻意表演（masking），需多文本跨语境验证。

## 与 LPP 其他层的关系

- 上游：`lpp-register`（语域校准，排除文体 confound）
- 并行：`Step 1.5 ND2（系统化加工标记）`——ND 问"是否 ND 来源"，cogstyle 问"方向"
- 下游：可增强 `Step 3` 大七 O（开放性）/ A（行事风格）解释——但需标注 △ 探索性
