# lpp-lsm — 语言风格匹配度

> LPP 言灵包子技能 · 人际维度（双文本）· △ 探索性层 · v1.2 脚本驱动

## 概述

语言风格匹配（Language Style Matching, LSM）指两个人说话的功能词/节奏/语气/情绪模式越相似，关系越近、沟通越有效。本子技能从**双方文本**（对话记录或两人各自样本）计算 LSM，输出同频分数与关系维度推论。

**与 LPP 其他子技能的本质区别**：lpp-vad/register/cogstyle 等都是**单方文本**分析（一个人的文本 → 一个人的心理状态，向内）；lpp-lsm 是**双文本**分析（两个人的文本 → 两个人之间的关系质量，向外）。输入必须是双方文本，单方文本不激活。

**v1.2 升级（2026-08-28）**：
- **S9 消息节奏（聊天特有）**：消息长度分布 + 消息内句数 + 时间戳间隔模式——纯文本聊天里"节奏"以消息粒度存在，与 S3 句节奏并列（对话模式 S3 10% / S9 10%）。
- **S2 并入表情**：语气词 + emoji + 颜文字合并为"语气标记密度"。
- **时间戳支持**：`[21:00] A: xxx` 或 `21:00 A: xxx` 前缀可解析，双方发送间隔模式进入 S9。

**v1.1 升级（2026-08-28，基于研究调研）**：
- **脚本驱动**：LSM 本质是频率统计，脚本计算（`lsm_compare.py`）比 LLM 人工估算精确——对齐 lpp-vad 调用 `vad_lookup.py` 的模式。
- **轨迹 > 静态分数**（Khaleghzadegan 2023）：单次 LSM 意义有限，多轮对话看趋势（上升=适配进行时）。
- **S6 拆双轴**（Babcock 2014）：语义相似（LSS）与风格匹配（LSM）是两个独立维度。
- **威胁情境边界**（Liu et al. 2011）：竞争/交易语境下同频可能反效果。
- **咨询/教练应用**（Schaper/Albano 2023）：同频可作工作联盟指标。

**理论底本**（详见 vault `[[语言风格匹配·同频先于引导·2026-08-26]]`）：
- Ireland et al. (2011, *Psychological Science*)：LSM 预测关系启动与稳定——speed date 互选 OR≈3.05；86 对情侣 IM 文本，LSM 高者 3 个月后仍在一起 76.7% vs 53.5%（⚠️ 是 3 个月，不是"三年"）。
- Niederhoffer & Pennebaker (2002)：LSM 原始论文——⚠️ LSM 与互动质量评分无关（coordination-engagement 假说）：同频是"投入"刻度，不是"舒适"保证。
- Stephens, Silbert & Hasson (2010, *PNAS*)：讲者-听者脑活动时空耦合，耦合越强理解越好。
- Chartrand & Bargh (1999)：变色龙效应——自动模仿提升好感。
- Pennebaker 团队：LSM 基于功能词（LIWC），分数 0.50–1.00。

## 工具调用（脚本驱动）

```bash
python _Skills/yanling-lpp/scripts/lsm_compare.py -a 文本A.txt -b 文本B.txt          # 双方独立样本
python _Skills/yanling-lpp/scripts/lsm_compare.py -d 对话.txt                         # 对话文本（A:/B: 前缀自动分离）
python _Skills/yanling-lpp/scripts/lsm_compare.py -a a.txt -b b.txt --json            # JSON 输出（供报告消费）
python _Skills/yanling-lpp/scripts/lsm_compare.py -d 对话.txt --segments 5            # 轨迹模式：分 5 段看 LSM 趋势
```

- 依赖：系统 Python 3.12 + jieba；自动复用 `_Skills/dream-iea/scripts/vad_lookup.py`（S5 情绪同频）。
- 对话格式支持时间戳：`[21:00] A: xxx` / `21:00 A: xxx`（有则算双方发送间隔模式，并入 S9）。
- 脚本输出：LSM 分数（0-1）+ 判定（≥0.75 高 / 0.55-0.75 中 / <0.55 低）+ 各维相似度 + 双方 VAD 坐标 + 文本长度。
- 维度覆盖：独立样本模式 S1/S2/S3/S5/S6（S3 权重 20%）；对话模式自动启用 **S9 消息节奏**（S3 10% / S9 10%）。
- **S7/S8（正式度/句式镜像）脚本不计算**，由 LLM 阅读文本补充观察后并入最终报告。
- 脚本内置功能词表与 `references/lsm-zh.md` 同步（△探索性）；权重：S1 30% · S3 20%(对话 10%) · S9 10%(对话) · S5 20% · S6 15% · S2 10%（S7 5% 由 LLM 补）。

## 输入格式（双模式）

**模式 A：对话文本**（首选）
- 两人聊天记录/对话稿，至少 10 轮对话，双方各 ≥200 字。
- 自动分离发言人（标注 A/B），按人聚合计算。
- 群聊（≥3 人）不激活——参照 LPP 主流程规则 11。
- 对话格式：`A: 内容` / `B: 内容` 前缀（支持 甲/乙/我/你/ta），或空行分块轮流归人。

**模式 B：双方独立样本**
- 两人各自的文本各一段（自我介绍/日记/邮件/朋友圈），各 ≥200 字。
- 注意文体对齐：对比"日记 vs 日记"或"邮件 vs 邮件"，不做跨文体直接比较（参照 LPP 语域校准原则）。

**置信度**：双方各 ≥200 字 → 标准；各 100–200 字 → 受限（仅出 LSM 分数不出关系推论）；任一方 <100 字 → 不激活。

## 轨迹模式（v1.1 新增 · 推荐用于对话）

- 单次静态 LSM 与"当下体验"脱钩（2002 原始论文）且与感知相关性弱（Khaleghzadegan 2023）——**优先使用 `--segments N` 看趋势**。
- 轨迹解读：上升（首段 < 末段 -0.05）= 适配进行时，关系在趋近；下降 = 同频在瓦解；持平 = 稳定（或一直不同频）。
- 趋势比单点分数更有报告价值。

## S1–S8 观察维度

| # | 维度 | 观察要点（中文） |
|---|------|-----------------|
| S1 | 功能词分布 | 代词（我/你/咱们）、助词（的/了/着）、连词（但是/因为/所以）、量词使用频率与比例相似度 |
| S2 | 语气词谱 | 语气词种类与频率（吧/吗/呢/啊/哈/嗯/嘛）——同频者语气词谱接近 |
| S3 | 句长节奏 | 平均句长、长短句交替模式、断句习惯（一逗到底 vs 短促成句） |
| S4 | 填充词/话语标记 | "就/然后/那个/其实/怎么说呢"的位置与频率——功能词层的潜意识信号 |
| S5 | 情绪同频 | 双方 VAD 效价/唤醒分布的距离（联动 `lpp-vad`：双方 V_μ/A_μ 坐标距离小 = 情绪同频） |
| S6 | 内容呼应 | **双轴（v1.1）**：① LSS 语义轴——关键词复现、话题承接、引述原话（脚本近似：非功能词 top 词交集率）；② 风格轴归 S1。两轴独立：风格匹配 ≠ 内容共鸣（Babcock 2014） |
| S9 | 消息节奏（聊天特有·v1.2） | 消息长度分布、消息内句数、发送间隔模式（时间戳可选）——纯文本聊天里"节奏"以消息粒度存在（Ireland 2011 用 IM 文本正是此粒度）；仅 -d 对话模式激活 |
| S7 | 正式度层级 | 书面/口语层级、敬语密度、表情包/语气颗粒度是否一致 |
| S8 | 句式镜像 | 反问/设问/感叹/省略句偏好一致性；"先结论后细节" vs "先叙事后总结"的骨架是否互锁 |

## 评分规则

**脚本计算**（优先）：`lsm_compare.py` 输出各维相似度 + 加权分数：
- 独立样本权重：S1 30% · S3 20% · S5 20% · S6 15% · S2 10%（S7 5% 由 LLM 补）。
- **对话模式权重**：S1 30% · S3 10% · **S9 10%** · S5 20% · S6 15% · S2 10%——S9 消息节奏从 S3 拆出（聊天场景节奏=句+消息双粒度）。
- S5 情绪同频有"证据回退"：双方情绪词命中率低时回退中性分 0.5（短文本无情绪词 ≠ 情绪同频）。
- 判定：≥0.75 高同频 / 0.55–0.75 中同频 / <0.55 低同频。
- **对话文本优先跑轨迹模式**（`--segments`），趋势比单点分数更有报告价值。

**LLM 补充观察**（脚本不覆盖的）：S7 正式度层级、S8 句式镜像、单向适配检测（一方主动靠拢另一方 → 标注"单向同频"，可能是讨好/配合，不直接解读为关系好）。

**方向判定**：同频是双向自然趋同，还是单向镜像——看 S6 内容呼应的**互惠性**（A 呼应 B 与 B 呼应 A 的比例是否接近）。

## 应用场景（v1.1 新增）

- **咨询/教练工作联盟评估**（Schaper 2023 / Albano 2023）：咨询师/教练与来访者的同频可作联盟指标——早期 LSM 反映关系建立，趋势上升预示投入加深。**直接适用于 ND 教练服务**：每次会话后跑一次 LSM，追踪联盟曲线。
- **关系质量体检**：情侣/朋友对话跑轨迹模式，看长期趋势。
- **沟通适配自查**：自己 vs 对方样本对比，定位"我在哪个维度没跟上"（S1 功能词？S3 节奏？）。

## 重要限制

- **相关 ≠ 因果**（Ireland et al. 2011 作者自认）：是同频的人关系好，还是关系好的人更同频——双向促进，本技能只描述现状不预言未来。
- **LSM 与"当下体验"脱钩**（Niederhoffer & Pennebaker 2002 原始论文）：同频是"投入"的刻度，不是"舒适"的保证——报告里不要把高分说成"聊得来"。
- **静态分数意义有限**（Khaleghzadegan 2023）：单次 LSM 与感知相关性弱，**优先看轨迹**。
- **威胁情境**（Liu et al. 2011）：竞争/交易语境（谈钱、谈判）下被模仿者感到威胁——同频不是万能润滑剂，报告需注明语境。
- **实证失真提醒**：网络上"功能词相似度 70% 三个月三倍""三年后概率高 50%"等说法未核证到原始出处或系误传（实际：speed date OR≈3.05；3 个月随访 76.7% vs 53.5%），引用时以本研究为准。
- **非诊断**：本技能描述"文本匹配度"，不推断人格、不裁决关系、不替代专业评估。
- **语域校准前置**：跨文体对比（日记 vs 邮件）会污染 LSM——先做 `lpp-register` 校准或仅对比同类文体。
- **ND 注意**：ASD 者口语-书面风格差异可能被误判为"低同频"——结合 `Step 1.5 ND 校准` 与 `lpp-cogstyle` 排除认知风格 confound（ASD 高信息密度 ≠ 关系差）。
- **短文本分级**：<200 字不激活；群聊（≥3 人）不激活；脚本 S5 情绪证据不足时自动回退中性分。

## 与 LPP 其他层的关系

- 上游：`lpp-register`（语域校准，排除文体 confound）；`lpp-vad`（S5 情绪同频的数据来源）
- 并行：`Step 1.5 ND 层`（排除认知风格 confound）；`lpp-cogstyle`（认知风格差异可能压低 LSM——风格错位不必然是关系问题）
- 下游：可增强 `Step 3` 依恋风格归纳中的"关系互动模式"部分（安全型依恋通常 S6 内容呼应互惠性高）——需标注 △ 探索性
- 姊妹篇：`夸人三层次`（给予侧）与 `情绪价值批判`（索取侧）——LSM 是这两者的语言层测量工具
